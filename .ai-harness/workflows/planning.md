# Planning Workflow

Purpose: create implementation plans for multi-file changes or architectural
decisions.

Steps:

1. Confirm the issue or work item that owns the change.
2. Identify the files and template surfaces likely to be affected.
3. Write ordered, concrete implementation steps.
4. Include dependencies, open questions, and verification strategy.
5. Post the plan to the issue for multi-file or architectural work.
6. Track progress visibly while implementing.

Plans should be specific enough to guide implementation without duplicating
the final code.
